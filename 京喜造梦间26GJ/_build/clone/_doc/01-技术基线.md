# 《借你一秒》技术基线（阶段 1 · 提示词 1 产出）

> 对应手册：提示词 1「项目总控指令」。本文件是工程审计结论 + 后续所有阶段共同遵守的技术边界。

## 1. 工程审计结论

| 项目 | 实际情况 | 对开发的影响 |
|---|---|---|
| Unity 版本 | **6000.3.8f1**（`ProjectSettings/ProjectVersion.txt`） | 手册要求"使用当前安装版本，不要擅自升级"。本机编辑器 `D:\Unity6\Editor\Unity.exe` 同为 6000.3.8，**不需要升级**。 |
| 渲染管线 | URP 17.3.0（`com.unity.render-pipelines.universal`） | 2D 游戏直接用 URP；**不新增管线包**。 |
| UGUI | `com.unity.ugui` 2.0.0 已安装 | **UI 用 UGUI**，可以全部由代码创建。 |
| TextMeshPro | **未安装** | 关键决定：**不使用 TMP**，用 UGUI `Text` + 内置 `LegacyRuntime.ttf` 字体，避免缺包/缺字体资源导致编译或运行失败。 |
| Input System | `com.unity.inputsystem` 1.18.0 已安装 | 但 UGUI 的 `EventSystem` 默认走旧 Input。方案：脚本里**只用 UGUI 事件与 `Input.GetMouseButtonDown` 兜底**，不依赖 Input System 的 Action 资产，避免"InputSystemUIInputModule 缺引用"这类经典坑。 |
| 3D / Tilemap 等模块 | 均随引擎提供 | 占位美术用 UGUI `Image` 纯色几何图形拼，**不依赖任何贴图/美术资源**。 |
| 已有脚本 | 只有 `Assets/TutorialInfo/Scripts/Readme.cs`（模板自带） | **不动它**，不改无关文件；所有游戏代码放 `Assets/Scripts/`。 |
| 现有场景 | 只有 `Assets/Scenes/SampleScene.unity`（URP 空场景） | 新建 `Assets/Scenes/Main.unity` 作为游戏入口，并把 Build Settings 场景列表指向它。 |

## 2. 目录与文件规划

```
Assets/
  Scenes/
    Main.unity              ← 游戏唯一入口场景，只挂一个 GameBootstrap 空物体
  Scripts/
    Core/
      GameManager.cs        ← 唯一总控：关卡流程、Ambition/Connection、倒流状态、结局判定
      GameState.cs          ← 纯数据：枚举、关卡/阶段定义、选择记录（无逻辑，便于调试）
      MemoryLevelData.cs    ← 三关的文案、选项、物件预设状态（数据驱动，方便改文案）
    View/
      SceneBuilder.cs       ← 代码生成 Canvas / 按钮 / 文字 / 可点击物件（避免手动拖引用）
      UiFactory.cs          ← 创建 UGUI 元素的工具函数（按钮三态、面板、文字样式）
      PlaceholderArt.cs     ← 用纯色几何图形拼人物/站台/木船/电话/刻痕（占位美术）
      ClickableActor.cs     ← 人物点击 → 选中反馈
      ClickableProp.cs      ← 物件点击 → 交互反馈
      RewindEffect.cs       ← 倒流可视化：残影、闪回、颜色变化（阶段 5 打磨）
    GameBootstrap.cs        ← 场景入口：创建 GameManager 并驱动
  Settings/ ...             ← URP 配置，保持原样
```

**核心脚本数量控制在手册要求的 3—5 个**（`GameManager` / `SceneBuilder` / `ClickableActor` / `ClickableProp` / `GameBootstrap`），其余为纯数据或纯工具文件。

## 3. 必须遵守的技术边界（贯穿全部阶段）

1. **不做真正的物理时间倒带**，不逐帧录制/恢复世界。全部用**预设状态切换**：事件后状态 / 倒流恢复状态 / 选择 A 状态 / 选择 B 状态。
2. **每关最多一次正式回溯**，只有被选中的人物及其相关物件回到之前状态；已获得的信息、已完成的关卡、已记录的选择**不清除**。
3. **不新增第三方插件、付费素材、联网服务**；不新增 Unity 包。
4. **不要求团队手动创建大量 Inspector 引用**：UI 与物件全部代码生成，场景里只有一个 `GameBootstrap`。
5. **不用 TextMeshPro**，不用外部字体文件。
6. 变量只有两个整数：`Ambition`、`Connection`，**不是善恶值**。
7. 代码必须能编译、可调试，不留伪代码 / TODO / 空方法。
8. 不做过度设计：简单状态枚举 + 少量布尔/整数变量，不建剧情引擎。

## 5. 时间轴纪律（手册第七条）

- 第 5 小时：必须能从开始界面玩到结尾。
- 第 7 小时：冻结核心功能。
- 第 8 小时：只做修复、测试、打包。
- **先做完整流程，再做视觉打磨**；不为加功能牺牲一个已经能跑通的完整作品。
