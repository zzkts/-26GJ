## 五、如果出问题，从哪里排查

| 现象 | 排查位置 |
|---|---|
| Play 后画面全黑、没有任何 UI | 看 Console 有没有 `[借你一秒]` 开头的报错；确认场景是 `Main.unity` 且里面 `GameBootstrap` 的脚本引用没丢 |
| 按钮点不动 | 确认场景里有 `EventSystem`（`GameBootstrap` 会自动补）；看 Console 是否报 `StandaloneInputModule` 相关 |
| 文字显示成方块 | 内置字体 `LegacyRuntime.ttf` 取不到时会整段文字不显示，看 Console 报错 |
| 编译报 `error CS` | 直接跑 4.2 的第一个命令，会输出带行号的编译错误 |
