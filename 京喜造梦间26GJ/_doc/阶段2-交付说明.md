# 阶段 2 交付说明 · 第一关「站台上的一秒」核心原型

> 对应手册：**提示词 2「实现核心玩法原型」**
> 结论：核心原型的**代码与流程规则已完成并通过自动化断言**；
> 画面观感（是否好看、点击是否顺手）需要一次人工 Play 验收，见第四节。

## 一、这一轮兑现的手册要求

| 手册要求 | 兑现方式 |
|---|---|
| 1. 点击人物后进入选中状态 | `ClickableActor` + `SceneBuilder` 的选中光圈（放大 6% + 琥珀色光晕）与头顶情绪气泡 |
| 2. 点"倒流"后人物回到事发前状态 | `GameFlow.RequestRewind()` → `CompleteRewind()` 切到 `PropState.BeforeEvent`；`RewindEffect` 播放闪屏 + 时间轴回退 + 残影 |
| 3. 倒流后显示两种选择 | `GameFlow` 进入 `AwaitingChoice`，`GameManager` 显示两个选择按钮（文案来自数据表） |
| 4. 选择后场景发生可见变化 | `PropState.ChoiceA / ChoiceB` 重建舞台：木船被留在黄线外 / 被抱回怀里 |
| 5. 可进入下一步或重开本段 | 「进入下一段记忆」与常驻的「重开本段记忆」按钮 |
| 6. 标题／操作说明／当前事件／结果 | 顶部章节标题 + 变量条；底部三行（旁白 / 当前提示 / 选择结果）；右上角常驻操作提示 |
| 7. 实际能跑、不依赖缺失素材 | 无任何贴图/字体/插件依赖；全部 UGUI 代码生成 |
| 3—5 个核心脚本 | 核心 5 个：`GameFlow` / `GameManager` / `SceneBuilder` / `ClickableActor` / `ClickableProp` |
| 不用真物理倒带 | 只用 `PropState` 四态切换 |
| 不新增插件 | 未改 `Packages/manifest.json` |
| 关键注释、无伪代码/TODO/空方法 | 已逐文件确认 |
| 空引用 / 重复点击 / 重复倒流防护 | 所有输入先过 `GameFlow` 阶段校验；`_flowBlocked` 吞掉演出期间的输入 |
| 不要求手动拖引用 | 场景里只有一个 `GameBootstrap` |

## 二、第一关的四种预设状态（手册的"预设状态切换"）

| 状态 | 舞台表现 |
|---|---|
| A · 事发之后（`AfterEvent`） | 孩子背对母亲站着，情绪气泡"没有回头"；木船不在他手里（在母亲手上） |
| B · 倒流恢复（`BeforeEvent`） | 时间退回半分钟前，情绪气泡"还在犹豫"；木船回到孩子手里，列车未开动 |
| C · 选择 A（`ChoiceA`） | 男孩冲向列车，木船被留在站台黄线外 |
| D · 选择 B（`ChoiceB`） | 男孩站住，把木船抱回怀里，母亲的手停在他肩上 |

## 四、交给你的第一次 Play 验收（手册要求"每轮执行后都应在 Unity 中实际运行并检查"）

1. Unity Hub 打开 `D:\114514\GitHub\-26GJ\京喜造梦间26GJ`，等导入完成。
2. 打开 `Assets/Scenes/Main.unity`，按 **Play**。
3. 菜单栏「借你一秒 → 2. 视图绑定自检」：它会检查 Canvas / EventSystem / 主角可点性 /
   关键物件 / 按钮 / 并**真的模拟点一次主角**，把结果打到 Console。
4. 手工走一遍验收流程：
   `开始这段走马灯 → 点站台上的孩子 → 点“借他一秒” → 选一个行动 → 看人物与木船变化 → 进入下一段记忆 / 重开本段记忆`
5. 重点确认（这几项只有人眼能判断）：
   - 画面里的孩子、母亲、列车、木船**看得懂**
   - 倒流动画**看得见**（紫闪 + 时间轴 + 残影）
   - 两个选择按钮的文案和位置**不挡画面**
   - 文字没有超出窗口或被遮挡

## 五、如果出问题

| 现象 | 先看哪里 |
|---|---|
| 点击人物没反应 | Console 里「视图绑定自检」的报告；它会直接指出哪个人物没有接管射线 |
| 倒流按钮一直不可点 | 确认是否已先点中主角（未选中时按钮故意保持不可用，用来告诉玩家下一步） |
| 舞台物件位置偏 | `SceneBuilder.SlotPosition()` 与 `BuildProp()` 里的锚点常量，都在 `View/SceneBuilder.cs` |
