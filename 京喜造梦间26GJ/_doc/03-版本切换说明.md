# 两个版本的存放与切换

工程里现在**有两套完整的游戏**，同一时间只有一套是"活的"（被 Unity 编译）。

| | 《借你一秒》（旧版 / 第一版） | 《错过了那一秒》（新版） |
|---|---|---|
| 当前状态 | 📦 已归档 | ✅ **活的** |
| 代码位置 | `Assets/_借你一秒~/Scripts`、`.../Editor` | `Assets/Scripts`、`Assets/Editor` |
| 运行时美术 | 无（全部程序化） | `Assets/Resources/Art`（9 张贴图，约 39 MB，会进包） |
| 源图与成品 | — | `Assets/Art/`（`.doc/ART_*.md` 里记录的就是这批） |
| 玩法 | 点击选人 → 借他一秒 → 四态切换 → 三结局 | 拖世界内滑块 → 连续时间轴 → 借时债务 → 唯一结局 |
| 打包产物 | `Build/Windows_借你一秒/JieNiYiMiao.exe`（96.5 MB） | `Build/Windows/CuoGuoNaYiMiao.exe`（约 177 MB） |
| 打包入口 | `JieNiYiMiao.EditorTools.BuildScript.BuildWindows` | `CuoGuo.EditorTools.BuildScript.BuildWindows` |
| 验证方式 | `_build/verify-old/`（恢复后补的 14 项流程验证） | `_build/verify/`（内核 75 组 + 运行时 43 组） |

归档文件夹的名字**以 `~` 结尾**，Unity 会完全忽略它——不编译、不导入、不进包，但文件一个都没少。
所以切换只是"改文件夹名"，不会丢任何东西。

---

## 怎么在两版之间切换

思路都一样：**把当前活跃的那套挪进 `~` 归档夹，把想用的那套挪出来**，然后重新生成入口场景。

目前活跃的是新版《错过了那一秒》。想切到旧版《借你一秒》：

```powershell
cd <工程>

# 1. 新版挪进归档
New-Item -ItemType Directory -Force -Path "Assets\_错过了那一秒~" | Out-Null
Move-Item "Assets\Scripts"   "Assets\_错过了那一秒~\Scripts"
Move-Item "Assets\Editor"    "Assets\_错过了那一秒~\Editor"
Move-Item "Assets\Resources" "Assets\_错过了那一秒~\Resources"

# 2. 旧版挪出来
Move-Item "Assets\_借你一秒~\Scripts" "Assets\Scripts"
Move-Item "Assets\_借你一秒~\Editor"  "Assets\Editor"

# 3. 用旧版自己的脚本重新生成入口场景
& 'D:\Unity6\Editor\Unity.exe' -batchmode -quit -nographics -projectPath "<工程>" `
  -logFile "<工程>\_build\scene.log" `
  -executeMethod JieNiYiMiao.EditorTools.ProjectSetup.SetupScene
```

**切回来就是把上面反过来**（用 `CuoGuo.EditorTools.ProjectSetup.SetupScene` 重新生成场景）。

新版切回后可以用它自己的验证脚本确认没坏：
`Assets\_错过了那一秒~\_verify\` 里有备份，拷回 `_build\verify\` 再跑即可 —— 正常情况下它们是同步的。

```powershell
$sb = [ScriptBlock]::Create((Get-Content '<工程>\_build\verify\rebuild-and-check.ps1' -Raw -Encoding UTF8))
& $sb
```

## 切换时必须注意的三件事

### 1. 入口场景要重新生成

两个版本的 `GameBootstrap` 是**不同命名空间下的同名类**。`Assets/Scenes/Main.unity` 里挂的是哪一个，
取决于最后一次生成它的是谁。切版本后如果直接 Play，会看到 "Missing (Mono Script)"。
用对应版本的 `ProjectSetup.SetupScene` 重新生成即可（旧版：`JieNiYiMiao.EditorTools.ProjectSetup.SetupScene`）。

### 2. 输入设置必须保持 `activeInputHandler: 2`

`ProjectSettings.asset` 里这一项现在是 `2`（**新旧输入都启用**）。

它原来是 `1`（只启用新输入系统）——那种设置下，旧版代码创建的 `StandaloneInputModule`
**收不到任何鼠标事件**，也就是界面按钮和点击在打包版本里点不动。
这一项是新版开发时发现并修掉的，**旧版因此也一并被救了**。切版本不要把这个值改回去。

### 3. 新版带 39 MB 运行时美术，旧版不带

新版的 `Resources/Art`（9 张压缩贴图，约 39 MB）会**无条件进包**，所以它跟着新版代码一起被归档了。
如果哪天想把两版合在一起（让旧版也能用那些贴图），记得先把这 39 MB 从 `Resources` 里移出去，
否则旧版的包会白白大 39 MB。

## 各自还有什么工具

| 工具 | 属于 | 位置 / 说明 |
|---|---|---|
| 菜单「借你一秒 / 1..4」 | 旧版 | 生成场景、播放自检、打包 |
| 菜单「错过了那一秒 / 1..7」 | 新版 | 生成场景、打包、处理美术、烘焙可编辑场景、导出时间轴、时间轴预览 |
| `_build/verify/run-verify.ps1` 等 | 新版 | **已被新版的脚本覆盖**；旧版原来的独立断言程序（23 组）随之被替换掉了 |
| `_doc/02-新版交付说明.md` | 新版 | 架构、验证证据、美术接入、已知限制 |
| `_doc/ART_*.md` | 新版 | 美术资产审计/修图日志/验收报告/资源映射/重生成提示词 |

**旧版原来的 23 组独立断言程序已经被覆盖，无法直接跑回。** 旧版仍可在编辑器里用
菜单「借你一秒 / 3. 播放状态下自检」做引擎内自检。这一点如实记在这里。
